# Security policy

## Supported scope

Please report vulnerabilities in the published contents of
`patobiskoto/patolabs-plugins`: plugin manifests, skills, tooling, hooks, scripts, and
GitHub Actions workflows. Reports about the private historical repository, a local
machine, credentials, or a third-party service are out of scope unless the report shows
how the published repository itself causes the impact.

## Report privately

Use GitHub's [private vulnerability reporting form](https://github.com/patobiskoto/patolabs-plugins/security/advisories/new).
Do not open a pull request, commit, GitHub Issue, or public discussion for a security
report. GitHub Issues are disabled for this repository.

Include a minimal reproduction, affected revision, impact, and any safe mitigation you
already know. Never include a live token, private key, credential, or personal data.

## Handling and disclosure

Maintainers will acknowledge and triage a report privately. A report does not trigger an
automatic public disclosure, publication of an advisory, release, or change to the
backlog. Any public disclosure is coordinated with the reporter after a fix or mitigation
is available.

## Contributions

External contributions are not accepted at this stage. This does not prevent private
security reporting through the route above.
